LicenseFlow Manager v1.1.0 설치 안내 (최종 업데이트 반영)

1. LicenseFlow_Release_v1.1.0 폴더를 원하는 곳에 압축을 풉니다.
2. 'install_setup.bat' 파일을 마우스 오른쪽 버튼으로 클릭하고 '관리자 권한으로 실행'을 선택합니다.
3. 설치가 완료되면 바탕화면에 바로가기가 생성되며 프로그램이 자동 실행됩니다.

[이번 버전 업데이트 사항]
- 실명 보호 로직 적용: PC 이름(Administrator 등)이 시트를 덮어써도 매니저에서는 실명을 우선 표시합니다.
- UI 안정성 개선 및 버그 수정 완료.
- 대표님이 사용 중인 v6.2 GAS 스크립트와 100% 호환됩니다.

[참고사항]
- 이 프로그램은 Windows 전용입니다.
- 백신 프로그램에서 차단할 경우 '허용' 또는 '예외 등록'을 해주세요.
